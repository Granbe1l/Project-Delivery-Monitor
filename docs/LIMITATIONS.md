# Limitations and outstanding validation

1. Live GitHub access is now verified in the published environment: 15 preflight checks passed, all three projects synced, and 12 sample source records matched. This verifies collected samples, not every repository record or the full population. See LIVE_VALIDATION.md.
2. Deployment templates are prepared, but Render/Vercel/managed PostgreSQL resources and periodic scheduling have not been created or enabled. No costs were incurred by provisioning services.
3. Default bounded collection often produces partial coverage for large projects. It favors recently updated open items, so old inactive items may be absent. Absence is not proof that no older item exists. Increase budgets only after checking available quota.
4. GitHub pagination is subject to concurrent upstream edits. Full historical record revisions, merge/close event timelines, detailed reviews, conditional ETag caching, and cross-repository rankings are not implemented. Observation tables show actual snapshots, not a fabricated historical chart.
5. The text brief is implemented; PDF export is deferred and no PDF button is shown. Tables support pagination, search, creation-period filters and CI branch filters. Milestones show at most 100 collected records with the actual displayed/collected count.
6. Requests use a 20-second timeout and bounded retries. Long Retry-After/reset waits stop the job; operational rescheduling must respect the reported upstream limit. No in-process scheduler or keepalive workaround is used.
7. Integration tests use PostgreSQL and synthetic TEST DATA in a separate test database. They verify invariants but cannot replace a live source comparison. The `*-live-*.png` screenshots show actual GitHub observations. The original screenshots preserve the earlier unavailable-data state. Three additional browser tests use the real API, covering all projects, search, pagination, evidence, history, export and mobile rendering without mocked data.
8. Basic keyboard controls, focus, semantic labels and mobile overflow are checked; this is not a formal accessibility audit. No production load, penetration, or provider integration test has been run. Configure edge limits, TLS and database backups before public operation.
9. CI workflow is prepared and its constituent commands ran locally; GitHub-hosted CI has not run because the code has not been pushed. One upstream Starlette/httpx test-client deprecation warning is currently emitted; tests pass.
10. The user published the cloud environment and the new instance restored the code/dependencies/database. That is distinct from deploying the application to a public URL. The current draft has not been edited or republished during live verification. Shared Desktop is declared enabled, but agent browser-control tools are unavailable; see PREVIEW.md.
